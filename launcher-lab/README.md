# Project launcher lab

A local-only comparison of five launcher concepts using the same project data:

1. Map + drawer
2. Workbench desk
3. Studio shelves
4. Project constellation
5. Product gallery

The prototype uses the proposed three-part taxonomy: Software, Research and
Writing. Serve this folder over HTTP and open `index.html`; no build is needed.

```sh
python -m http.server 8875
```

The prototype is intentionally separate from the published homepage.
